# Claude MCP Server Credentials

## Overview
This document provides instructions on obtaining and structuring the credentials needed to connect the Claude MCP Server (Gemini API) in the Vanij Platform.

---

## Credential Format
```json
{
  "GEMINI": {
    "api_key": "your-gemini-api-key"
  }
}
```

- The `api_key` is required for all chat and model operations.
- You can obtain your Gemini API key from the Google AI Studio or Google Cloud Console.
