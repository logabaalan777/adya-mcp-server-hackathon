# Looker MCP Server Overview

## What is the Looker MCP Server?
The Looker MCP Server is a connector within the Vanij Platform that enables seamless interaction with Looker BI platform using the Looker REST API.

---

## Key Features
- ✅ Retrieve dashboards, dashboard details, and looks
- ✅ Run queries and get explore/model metadata
- ✅ Create new looks and manage existing ones
- ✅ Use authenticated REST calls for secure interaction

---

## Capabilities
| Capability           | Description                                       |
|----------------------|---------------------------------------------------|
| Dashboard Access     | List and get details of dashboards                |
| Query Execution      | Run queries and get results                       |
| Model & Explore Info | Retrieve model and explore metadata               |
| Look Management      | Create and manage looks                           |

---

## Supported Looker Versions
- Looker 7.x+ (with REST API support)
- Requires HTTPS-enabled instance

---

## Security Notes
- Authenticated via **client_id/client_secret** (API credentials)
- All communications must be secured over HTTPS
- API credentials should be kept confidential

---

## Integration Use Cases
- Business intelligence dashboards
- Automated reporting and analytics
- Data exploration and visualization tools
