# JSON Examples for MCP-ALACRITTY Tools

## 1. Get Alacritty Config (`get_alacritty_config`)
```json
{
  "client_details": {
    "tool_name": "get_alacritty_config",
    "arguments": {
      "config_path": "C:\\Users\\USER\\AppData\\Roaming\\alacritty\\alacritty.yml"
    }
  }
}
```
